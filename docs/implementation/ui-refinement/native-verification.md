The tests exercised the bundled WebKit application, real neural simulation and MuJoCo/ONNX runtime. The Mac display was locked, so native acceptance checked DOM geometry and behavior. Browser screenshots cover rendered visual acceptance; these receipts do not claim manual inspection of native painting. Webcam tests supplied synthetic video, and the room check used the repository's loopback TURN fixture with `node-turn@0.0.6`, installed in an isolated temporary prefix. The fixture listened only on `127.0.0.1` and was stopped after testing. External-network room connectivity was not tested.

Two retained failures led to application fixes. `native-setup-close-race.log` records a queued close event clearing a newly opened wizard session, which partially applied a scene and left it paused. Closing now completes the correct wizard session exactly once. `native-setup-run-intent-race.log` records rapid cancellation/reopening losing the intended running state before the worker acknowledged resume. Pause requests now carry IDs, so only the matching acknowledgement clears the pending intent. Both regressions passed in the final setup receipt.

Earlier diagnostic artifacts are retained separately: `native-setup-focus-timing.log` reflects an immediate test assertion before the native close event, corrected to a bounded focus wait; `native-scenarios-startup-timeout.log` came from a simultaneous second native launch. Final suites ran serially. `native-scenarios-candidate2-partial.log` was deliberately stopped when the newer candidate became available and is not counted as a completed audit.
