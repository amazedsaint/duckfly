# Third-party notices

## DesktopFly

`mac/ThirdParty/DesktopFly/` copies `Sim.swift`, `Locomotor.swift` and `LegDynamics.swift` from Denis Shiryaev's DesktopFly, commit `32b00011e83c3dc85fa3ea0b3934155b04f1635d`. MIT license is retained in that directory. `web/src/vendor/desktop-fly/` copies the matching JavaScript port (`sim.js`, `locomotor.js`, `legdynamics.js`); DuckFly adds an injectable random source for independent, seeded circuit instances and per-neuron silencing before spike generation. DuckFly instantiates the 668-neuron FlyWire circuit without the MaleCNS locomotor network.

Source: https://github.com/DenisSergeevitch/desktop-fly

`shared/assets/Brain/circuit.json` and `brain_points.json` retain their CC BY-NC 4.0 terms. See `shared/assets/Brain/DATA_LICENSE.md`. Cite Dorkenwald et al., *Neuronal wiring diagram of an adult brain*, Nature 634, 124–138 (2024), DOI 10.1038/s41586-024-07558-y; and Schlegel et al., *Whole-brain annotation and multi-connectome cell typing of Drosophila*, Nature 634, 139–152 (2024), DOI 10.1038/s41586-024-07686-5. The display highlights the selected circuit; background whole-brain positions are not additional simulated cells.

## BAM

`mac/ThirdParty/BAM/bam/` is Better Actuator Models 1.0.1, source commit `62bd8ce12154340be97e06f7f41a0ca8f116d967` on `mjlab_frictionloss`. Original copyright headers and Apache-2.0 terms are retained. The package is bundled without its training stack; its CPU M6 model runs unmodified. `web/src/bam.js` ports the M6 friction and XL330 voltage equations for WebAssembly physics. It is checked against independently generated Python reference vectors. `shared/assets/Simulation/` retains the MuJoCo 3.10.0 reference model and configuration generated by `web/scripts/export-reference.py`. The editable `lab-template.json.gz`, generated by `export-lab-template.py`, preserves physical parameters and collision meshes while simplifying render-only frame markers and correcting the head camera orientation.

Source: https://github.com/Rhoban/bam

## Runtime dependencies

The retained reference application contains a Python Build Standalone interpreter, NumPy, MuJoCo and ONNX Runtime with their runtime dependencies. Its notices remain inside `Contents/Resources/Python`. SwiftUI and RealityKit are supplied by macOS. `mac/Engine/requirements.txt` specifies the reference versions. The current standalone workspace uses the same WASM dependencies as the browser, hosted by macOS AppKit/WebKit; it does not bundle Python.

The browser and standalone Mac workspace bundle `@mujoco/mujoco` 3.10.0 (Apache-2.0), `onnxruntime-web` 1.24.3 (MIT), and Three.js 0.186.0 (MIT). Their versions and transitive dependencies are locked in `web/package-lock.json`. Runtime license files are served under `/assets/licenses/`.

## Flyvis reference visual model

The optional retinal bench includes the full early-vision model from
[TuragaLab/flyvis](https://github.com/TuragaLab/flyvis), pinned to commit
`92b3845cc426dd309a1a0e1b3890156c42e14021`, and the published `flow/0000/000`
checkpoint. Upstream code is MIT; its license is retained at
`shared/vision/models/flyvis-000/LICENSE`. The source archive SHA-256 is
`71c78d4070556a536b13b23ee3139cd2788aa2a9d07d430a223b4edead281db1`.
See [Lappalainen et al., Nature 2024](https://www.nature.com/articles/s41586-024-07939-3).

DuckFly's sparse runtime is an equivalent implementation of the published
continuous-state equations. The compact motion-opponency detector and its
LPLC2 current mapping are DuckFly modeling assumptions, not the Flyvis model.
No FlyGym, Clark Lab or Murthy Lab code is redistributed by this upgrade.
