# Clear-marker identity candidate v1

Written before implementation and held-out evaluation. This is an engineered color-marker tracker, not a model of LC10/LC9 or a fly circuit. Inference receives96×64 RGBA frames with capture time and stream/frame identity. It must not read scene-object IDs, poses, stimulus family or ground-truth target location.

Compare against the current `VisionEncoder` whole-image magenta centroid on exactly the same frames. Keep the same pixel color predicate to isolate the value of component separation and temporal association. Acquire an identity only from a unique compact component that persists for at least120ms. Reject image-wide flashes. Track component appearance and motion with conservative gates. An unresolved merge between similar markers latches uncertainty until explicit reset; no hidden target position should be reported as a live measurement. Short occlusions can recover only when the image history has not introduced competing identity evidence. Long loss requires reset.

New synthetic movie families: isolated marker, separated same-color distractor, same-color crossing/merge, brief occlusion, ambiguous occlusion, close distractor appearance, full-field flashes, brief local flashes, no marker, camera-like image shift and prolonged disappearance followed by another marker. Calibration uses6 deterministic seeds per family; frozen-source held-out evaluation uses24 new seeds per family, different spatial phases, contrast and capture cadences. The generated movies and exact labels remain separate from inference. Do not retune against held-out outcomes.

Gates: zero confident identity substitutions after unresolved merge/ambiguous occlusion; no reported target on no-marker or brief-flash movies; at most1% wrong visible-frame positions (>3 pixels from the true visible center) in the safe tracking families. Conditional visible-frame coverage must be at least90% after a200ms initialization interval for isolated, separated-distractor and camera-shift families. Report occlusion reacquisition delay and coverage separately; target identity cannot be recovered from perfectly indistinguishable objects without additional information. Abstention is an explicit result, not a correct position. Movie-level counts and all individual outcomes are retained.

Test exact checkpoint continuation, source change, duplicate/out-of-order frames and explicit reset. Keep stream identity separate from object identity. Fresh restore/reset must never retain a stale target association. Test a real-rendered transfer cohort using the unchanged actual LabArena renderer, including same-color crossings and an opaque occluder, before considering any application integration. No body or policy promotion follows from image tracking alone.
